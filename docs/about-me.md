# About Me

I build things for the web and occasionally write them down. This site is one of those write-downs — a folder of markdown files that gets rendered in the browser instead of a CMS I'd have to maintain.

## What I work with

- JavaScript, mostly vanilla when I can get away with it
- Python for scripts and glue code
- A healthy suspicion of frameworks I don't strictly need

## Why this site exists

Most portfolio templates want you to fill out a form or wrestle with a headless CMS just to publish a paragraph. I wanted something where adding a project is: write a `.md` file, add one line to a manifest, push. That's it.

> No database. No build step. No admin panel to forget the password to.
