- Dark mode by default, light mode as a toggle. Most of the time I'm reading this at night anyway.

## Things that bit me

Fetching local `.md` files with `file://` doesn't work — browsers block it as a CORS issue. Took a minute to remember that's not a bug, it's just how `fetch` behaves outside `http://`. Fix was running a local server for testing:

```bash
python3 -m http.server 8000
```
